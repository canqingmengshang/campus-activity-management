# 01 项目启动说明


## 1. 项目名称
校园活动报名与签到管理系统

## 2. 项目背景
为满足校园内各类学术讲座、文体活动、社团招新、竞赛比赛等活动的组织管理需求，学校计划建设一套轻量化、流程化、易使用的活动管理工具，实现活动发布、学生报名、资格审核、现场签到、数据统计一体化管理，提升活动组织效率与数据可追溯性。

## 3. 项目目标
- 支持活动管理员发布、编辑、下架活动，配置活动时间、地点、人数上限、报名起止时间
- 支持学生浏览活动、在线报名、查看个人报名状态与审核结果
- 支持活动组织者对报名名单进行审核、导出、查看详情
- 支持现场工作人员通过名单或二维码完成快速签到与异常处理
- 支持活动签到率、出席率、人员结构等数据统计与报表导出
- 完成全套项目管理文档交付，并通过Git完成版本控制、协作开发与冲突解决实验

## 4. 团队分工
- 刘广兴：项目经理 + 计划负责人
  职责：
    - Git仓库创建、目录结构规划、权限管理
    - 项目整体统筹、进度监控、风险把控
    - 文档审核、分支合并审批、最终版本确认
    - 组织小组沟通、确保实验按要求完成

- 陈文裕：配置管理员 + 协作成员
  职责：
    - WBS分解、进度计划制定、范围管理
    - 分支策略制定、提交规范、冲突处理
    - 配置项管理、版本留痕、过程记录
    - 协助完成文档编写、协作提交与实验总结

## 5. 项目边界
### 纳入范围
- 活动信息发布、编辑、查询、维护功能
- 学生在线报名、取消报名、状态查询功能
- 报名名单审核、通过/驳回管理功能
- 现场签到、签到状态修改功能
- 签到数据统计、结果导出功能
- 项目管理全套文档：启动说明、WBS、进度计划、配置管理、总结报告
- Git版本控制、分支协作、冲突解决、主分支合并

### 不纳入范围
- 支付、收费、发票、退费等财务相关功能
- 与学校统一身份认证、教务系统、学工系统深度对接
- 高并发架构设计、服务部署、服务器配置、安全加固
- 移动端App原生开发、小程序发布、第三方平台对接
- 消息推送、短信通知、邮件提醒等扩展功能
- 复杂权限体系、多级审批、后台管理平台完整开发

## 6. 主要交付物
- 规范的Git项目仓库与标准目录结构
- 项目启动说明文档
- 三级交付物导向WBS文档
- 简化进度计划文档
- 配置管理方案文档
- 冲突解决过程记录
- 两人共同完成并合并至main分支的实验总结报告
